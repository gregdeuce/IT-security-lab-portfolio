# GVM/OpenVAS Vulnerability Assessment Lab

## Objective
Configured Greenbone Vulnerability Management (GVM) to perform
authenticated and unauthenticated vulnerability assessments.

## Environment
- Kali Linux
- GVM/OpenVAS
- Metasploitable 2
- Oracle VirtualBox
- Host-only network
- SSH authenticated scanning

## Tasks Completed
- Installed and configured GVM
- Configured OpenVAS scanner
- Loaded vulnerability feeds
- Created scan targets
- Configured SSH credentials
- Performed unauthenticated scan
- Performed credentialed scan
- Analyzed QoD and CVSS results
- Generated vulnerability assessment report

## Results
- Credentialed scan completed successfully
- Unauthenticated scan completed
- Compared authenticated vs. unauthenticated findings
